How to read this page

Each entry follows the same four-part shape.

Anatomy of an entry

The plain-English line says what the formula is for. The mathematics gives the definition. The ports table lists the exact field names the API expects and the values used in the example. The screenshot shows that request and its response in the dashboard, so you can confirm the shape before writing any code.

Every port accepts either a literal number, a JSON array for series inputs, or {"node": "name"} to read another node's output — which is how formulas chain together into a model.
